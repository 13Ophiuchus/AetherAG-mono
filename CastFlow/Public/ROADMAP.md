# CastFlow Roadmap

Version: 1.0

Status: Active

---

# Vision

CastFlow aims to become the premier open-source wireless display platform for Apple platforms.

The project is built around four guiding principles:

- Security First
- Swift Native
- Modular Architecture
- Enterprise Ready

The AirPlay-compatible receiver remains fully functional without blockchain connectivity. Optional Flow services provide licensing, plugin distribution, subscriptions, enterprise management, and marketplace functionality.

---

# Strategic Goals

## Core Platform

Deliver a production-quality AirPlay-compatible receiver featuring:

- Bonjour Discovery
- RTSP Session Management
- RTP Media Transport
- VideoToolbox Hardware Decoding
- Metal Rendering
- CoreAudio Playback

---

## Plugin Ecosystem

Build a first-class extension framework that enables:

- Recording
- OBS Integration
- Discord Integration
- Automation
- Analytics
- Enterprise Extensions

---

## Developer Experience

Provide:

- Excellent documentation
- Stable SDK
- Sample applications
- Code generation
- Automated testing
- Continuous integration

---

## Enterprise

Support:

- Fleet Management
- Remote Configuration
- Audit Logging
- Device Registry
- SSO
- Licensing

---

## Optional Flow Services

Flow is never required for casting.

Optional services include:

- Licensing
- Subscription Management
- Marketplace
- Plugin Distribution
- Revenue Sharing
- Device Registration
