# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the AetherAG security contact.
Include a clear description, affected component, reproduction steps, impact, and
any suggested mitigation. Do not include private keys, mnemonics, credentials,
access tokens, authorization codes, or personally identifiable information.

We will acknowledge reports within 72 hours and provide status updates during
triage. Please allow a reasonable remediation window before public disclosure.

## Scope

The policy covers AGWallet, AetherAG server and client components, AetherShared,
and maintained blockchain SDK forks in this monorepo.

## Sensitive-data handling

Reports and logs must never contain private keys, seed phrases, access tokens,
OID4VCI pre-authorized codes, holder proofs, complete credentials, or plaintext
identity documents.
