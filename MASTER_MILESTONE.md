# AetherAG Consolidated Master Milestones

> **Single source of truth:** Update task status only in this file.
> Module `MILESTONES.md` files are generated by `python3 scripts/sync_milestones.py`.
> Status values: `not_started`, `in_progress`, `blocked`, `done`.
> A task may be marked `done` only when its acceptance criteria are satisfied and relevant tests pass.

## Operating Rules

1. Do not manually edit generated module milestone files.
2. Use stable task IDs; IDs are never renamed after merge.
3. Completion commits should include `Milestone: <TASK-ID>` in the commit body or PR description.
4. Run `python3 scripts/complete_milestone.py <TASK-ID> --evidence "<test/build evidence>"` only after validation.
5. Run `python3 scripts/sync_milestones.py --check` before opening a pull request.
6. Keep secrets, keys, mnemonic phrases, credentials, and production endpoints out of milestone evidence.

## Status Legend

- `done`: Acceptance criteria and validation evidence are complete.
- `in_progress`: Implementation or tests are actively underway.
- `blocked`: Work cannot proceed until a recorded dependency is resolved.
- `not_started`: Planned but no implementation work has begun.
